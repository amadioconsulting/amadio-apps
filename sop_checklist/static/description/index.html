Frequently Asked Questions

Can I launch the same SOP on multiple records?

Absolutely! Each time you launch a template, a new independent checklist instance is created. You can launch the same template on thousands of records. Each has its own step completion status, timestamps, and evidence.

What does "critical" mean?

Critical steps must be completed before you can mark the checklist as complete. If any critical step is pending, an alert banner appears. This prevents premature workflow advancement—perfect for mandatory sign-offs, quality gates, or legal compliance checkpoints.

Can I print the checklist?

Yes! Odoo's built-in print functionality works with checklists. Print shows template name, all steps, completion status, dates, responsible users, and notes. Perfect for physical records or compliance documentation.

What models can I launch checklists on?

Any Odoo model: Sale Orders, Projects, Pickings, Invoices, Subscriptions, Tasks, custom modules, etc. You can optionally restrict a template to specific models via the "Applicable Models" field.

Can steps require evidence attachments?

Yes! Mark any step as "Requires Evidence" to mandate an attachment. Users cannot complete the step without uploading a file. Perfect for safety inspections, compliance photos, or document sign-offs.

How do I track who completed each step?

When a step is marked done, the system automatically records the user and timestamp. The "Completed By" and "Completed On" fields show this metadata. All changes are logged in the checklist's message thread for audit purposes.

Can I edit steps after launching a checklist?

Yes! The template defines the structure, but checklist steps are independent. You can edit notes, add evidence, or reopen steps. This allows flexibility while maintaining template consistency across launches.

Does it work offline?

SOP Checklist is a native Odoo module, so it follows Odoo's standard behavior. For offline capability, consider Odoo's native offline modules or sync your instance to a mobile device running the Odoo mobile app.

Can I duplicate templates?

Yes! Use the "Duplicate" button to copy any template with all its steps. Useful for creating variants or managing versions of SOPs across different departments.

Is there a limit to steps per template?

No! Create as many steps as needed. We've tested templates with 100+ steps. Organize long checklists into multiple templates by category or process phase for better usability.
