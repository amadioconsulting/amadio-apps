Stop Losing Track of Document Versions

Attach versioned documents to any Odoo record. Track revisions, view full history, and optionally require approval before a new version goes live.

Key Features

Version History

Complete audit trail of every document version. Never lose track of who changed what, and when. Full transparency from draft to superseded.

Archive, Never Delete

Old versions are marked as superseded, not deleted. Keep a complete record for compliance, auditing, and historical reference without cluttering your workspace.

Optional Approval Workflow

Require approval before a document version goes live. Perfect for contracts, SOPs, and critical documents. Draft states until authorized users approve.

Works With Any Model

Use on contracts, opportunities, projects, purchase orders, or any custom Odoo model. Simply inherit the mixin and you're ready to go.

File Type Agnostic

Upload PDFs, Word docs, spreadsheets, images, or any file format. Document Version Control handles it all without restriction.

Chatter Integration

Every version appears in the model's Chatter feed. Team notifications, comments, and discussion threads on specific versions are automatically tracked.

Frequently Asked Questions

Does Document Version Control work with Odoo's Documents module? +

Yes! Document Version Control is a complementary module that adds version tracking on top of any Odoo model. It stores versioned documents as ir.attachment records, so it integrates seamlessly with Odoo's document ecosystem and doesn't conflict with the Documents module.

Will old versions be permanently deleted? +

No. Old versions are marked as "Superseded" or "Rejected" in the version history, never deleted. This gives you a complete audit trail and ensures compliance with document retention policies. System administrators can view, reference, and restore old versions at any time.

How do I add document versions to my custom model? +

Simply inherit the document.version.mixin AbstractModel in your model class, and you automatically get the document_version_ids One2many field, version count, and action buttons. Add the template to your form view and you're done!

Can I require approval before a version goes live? +

Yes! When uploading a document, check "Approval Required" and the version will start in Draft state. Designated users can then review and approve the version, setting it to Active. Previous active versions are automatically superseded.

What file formats are supported? +

All file formats are supported: PDFs, Word documents, Excel spreadsheets, images, videos, archives, and more. Document Version Control stores any file type that Odoo's attachment system supports.

Can I see who approved/rejected a version? +

Yes. Each version tracks the author (uploader), the approval status, and who approved or rejected it (if applicable). Full tracking is logged in the Chatter timeline for complete transparency.
