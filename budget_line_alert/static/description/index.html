Frequently Asked Questions

Common questions about the Budget Alert module

Does this affect already-posted entries?
No. Budget checks only apply to new transactions being posted. Already-posted entries are not affected. You can retroactively enable budgets on analytic accounts without impacting historical data.
Can I have multiple analytic accounts with different budgets?
Absolutely! Each analytic account has its own independent budget settings. You can set different thresholds, periods, and alert recipients for each account.
What happens if I try to post over the block threshold?
The system will show a UserError message preventing the posting. The error message includes details about the current spend, block threshold, and would-be percentage. You can then adjust the transaction or modify the budget.
How often are spending calculations updated?
Budget spent amounts are computed in real-time when viewing the analytic account form. Spending is recalculated every time you access the account, ensuring current information.
Can I disable alerts temporarily?
Yes. Simply uncheck the "Enable Budget Control" checkbox on the analytic account. Budget checks will be skipped until you re-enable it.
What if I have multiple recipients for alerts?
All configured alert recipients receive email notifications when thresholds are reached. Add as many partners as needed using the Many2many field on the Budget Alert tab.
What budget periods are supported?
Monthly, quarterly, annual, and custom date ranges. For custom periods, specify exact "From" and "To" dates. The system calculates current-period spending based on your selection.
Does the module work with analytic distributions?
Yes. When account move lines use analytic distributions (allocating costs across multiple accounts), each account's proportional share is checked against that account's budget.
Can I get alerts only for the warn threshold?
Yes. Set your warn threshold to a reasonable percentage (e.g., 80%) and block threshold at 100%. You'll get alerts when approaching budget but transactions won't be blocked until you reach 100%.
Are there activity logs for budget alerts?
The module tracks the date of the last alert sent (Last Alert Date field). Email messages are stored in the mail system for audit purposes.
