The Template Problem Every Odoo Team Knows
As your template library grows, finding the right one becomes friction. Friction becomes shortcuts. Shortcuts become inconsistent, off-brand communication.

📜 100+ Templates, No Signal

Templates accumulate over time. Sales, support, purchasing, invoicing — they're all in the same flat list. Staff scroll endlessly or give up and type from scratch.

🎯 Wrong Template, Wrong Context

A sales rep confirms a delivery using the wrong template. A support agent sends a billing response when the customer wanted a shipping update. Small, avoidable errors.

🔁 Muscle Memory, Not Best Practice

People reuse the last template they saw, not the most appropriate one. Brand standards and legal language get bypassed through habit.

🆕 Onboarding Takes Longer

New staff don't know which templates to use for which situations. Without guidance built into the tool, this knowledge only comes from trial and error.

Key Features
🎯

Context-Aware Suggestions

Rules match templates to specific Odoo models and optional status/stage values. A "Quotation Sent" stage triggers different suggestions than "Order Confirmed."

📈

Usage Learning Per User

The module tracks which templates each user applies. Recently used templates appear in a dedicated section, prioritized by frequency.

🔢

Priority Scoring Engine

Each rule has a priority (0–100). Combined with usage frequency, the scoring algorithm always puts the most relevant template first in the list.

🌐

Works on Any Model

Create rules for sale orders, purchase orders, helpdesk tickets, project tasks, CRM leads — any model that uses Odoo's mail composer.

📊

Usage Analytics

Managers can view a usage analytics dashboard: which templates are used most, by whom, and in which contexts. Optimize your library based on real behavior.

⚙️

No-Code Configuration

All rules are configured through a clean UI: Settings → Technical → Email → Smart Template Rules. No developer involvement required.
