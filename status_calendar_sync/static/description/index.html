The Follow-Up Gap That Kills Deals
The most valuable actions in your workflow happen after a status change. Without automation, they depend entirely on memory and manual discipline.

🕳️ The Black Hole After "Confirmed"

A sale order gets confirmed, then nothing happens for 3 weeks until the customer calls wondering about delivery. The follow-up was supposed to happen — nobody scheduled it.

📋 Automation Rules Are Hard

Odoo's native automation rules are powerful but technical. Most users can't write domain filters or compute scheduled dates without developer help.

📆 Calendars Don't Reflect Reality

Staff calendars show meetings they booked manually. The workflow-driven events — follow-ups, check-ins, reviews — are in someone's notebook, not in Odoo.

👥 Team Handoffs Get Dropped

When records move from sales to ops, the responsible user changes — but no one creates the handoff event. The next step exists only in the outgoing person's memory.

Key Features
🔧

Any Model, Any Field

Configure rules for any Odoo model — sales, projects, helpdesk, CRM, manufacturing. Monitor any status field: state, stage_id, kanban_state, or custom fields.

📅

Configurable Event Timing

Set the event delay in days (0 = same day) and duration in hours. Perfect for same-day reminders, next-day follow-ups, or week-later check-ins.

👤

Smart User Assignment

Assign events to: the current user, the responsible user (via dot notation like user_id or project_id.user_id), or all followers on the record.

📝

Dynamic Event Names

Event name templates support {record_name} and {record_url} placeholders. Events are meaningful and linkable back to the source record.

⚙️

Auto Server Action Generation

When you save a rule, the module automatically creates the underlying Odoo server action and automation trigger. No manual setup in technical menus.

🏷️

Event Category Support

Assign a calendar event category to each rule so events from different workflows appear in distinct colors on the calendar view.

Who Benefits Most

💼 Sales Teams

Auto-schedule post-confirmation follow-ups, delivery check-ins, and renewal reminders. Nothing falls through the cracks after an order is placed.

🎧 Customer Support

Trigger customer satisfaction events after ticket resolution. Ensure every closed ticket has a follow-up date — without adding to the agent's manual workload.

🏗️ Project Management

When a project task moves to "In Progress," schedule a check-in. When it reaches "Review," book the sign-off. Milestones drive calendar events automatically.

⛪ Service Organizations

Non-profits, churches, and service orgs that handle appointments, registrations, and events. Status changes automatically populate staff calendars.
